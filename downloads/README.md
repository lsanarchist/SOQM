# Install SOQM

[Download SOQM 0.1.0-alpha.1](https://raw.githubusercontent.com/lsanarchist/SOQM/6c4c7c43543a43ca772c5cd2af3e6f2ba10de833/downloads/SOQM-0.1.0-alpha.1-curseforge.zip)

This is the original published alpha from commit
[`6c4c7c4`](https://github.com/lsanarchist/SOQM/commit/6c4c7c43543a43ca772c5cd2af3e6f2ba10de833).
Generated ZIPs are no longer tracked in `main`; local builds go to `dist/`.

Import this ZIP into a new CurseForge-compatible launcher profile. It contains
the full mod manifest and game overrides. The launcher downloads the third-party
mods from their original projects; Minecraft Java Edition and Java 21 are required.

[the verification summary](../reports/README.md). A complete graphical playthrough and long-term balance remain pending.
The automatic GitHub source-code archive is not an installation package.
