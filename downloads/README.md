# Install SOQM

[Download SOQM 0.1.0-alpha.1](https://github.com/lsanarchist/SOQM/raw/refs/heads/main/downloads/SOQM-0.1.0-alpha.1-curseforge.zip)

Import this ZIP into a new CurseForge-compatible launcher profile. It contains
the full mod manifest and game overrides. The launcher downloads the third-party
mods from their original projects; Minecraft Java Edition and Java 21 are required.

[Українська](../docs/INSTALL.uk.md) · [English](../docs/INSTALL.en.md) ·
[SHA256SUMS](SHA256SUMS)

This is an experimental alpha, with server and static validation documented in
`reports/`. A complete graphical playthrough and long-term balance remain pending.
The automatic GitHub source-code archive is not an installation package.
