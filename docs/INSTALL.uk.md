# Встановлення SOQM

**Shout Out to Questing Mayhem** — збірка для Minecraft **1.21.1**, **NeoForge 21.1.262** і **Java 21**. Використовуй версії, зафіксовані в релізі: довільне оновлення окремого мода може змінити рецепти, залежності й квести.

## Нова гра

1. Завантаж [SOQM-0.1.0-alpha.1-curseforge.zip](../downloads/SOQM-0.1.0-alpha.1-curseforge.zip) з папки `downloads/` репозиторію GitHub (кнопка **Download raw file**). Звір SHA-256 із [SHA256SUMS](../downloads/SHA256SUMS). Архів вихідного коду GitHub (`Source code`) і початковий архів Questing Mayhem не є готовим профілем збірки.
2. У CurseForge App вибери Minecraft → **Import** → **Import Profile .zip** → **Choose .zip file** і вкажи ZIP. Дочекайся завершення завантаження всіх модів. [Офіційна інструкція імпорту](https://support.curseforge.com/support/solutions/articles/9000197912) пояснює також вимоги до структури ZIP. Публікація збірки в каталозі CurseForge для такого імпорту не потрібна.
3. Перевір у налаштуваннях профілю Java 21 і виділену пам'ять. **6 GiB** — початкова рекомендація для перевірки, а не виміряна системна вимога. Не віддавай грі всю оперативну пам'ять: системі та лаунчеру також потрібен запас.
4. Запусти профіль, дочекайся головного меню та створи окремий тестовий світ. Перевір книгу квестів, пошук рецептів і збереження світу за [чеклістом](PLAYTEST.uk.md).

Якщо лаунчер не завантажив файл, перевір журнал імпорту й повтори завантаження з офіційної сторінки відповідного мода. Не підмінюй відсутній файл випадковою версією. Повідомлення про проблему має містити назву релізу SOQM, файл мода й текст помилки.

## Оновлення

Перед оновленням повністю закрий гру й зроби копію **всього профілю**, зокрема `saves/`, `config/`, `defaultconfigs/`, `local/`, `options.txt` і даних карт, якщо вони є. Збережи також ZIP попереднього релізу. Резервну копію тримай поза папкою профілю.

Імпортуй новий реліз у **новий профіль**. Спочатку відкрий копію світу й перевір завантаження, книгу квестів, прогрес, інвентар і ключові рецепти. Перенесення світу між релізами підтримується лише в межах, прямо зазначених у примітках до релізу. Повернення до старішої версії роби через резервну копію, а не через відкриття вже оновленого світу.

Назви `qm_*`, простір імен `qm` і стабільні ID квестів походять із бази Questing Mayhem. Їх збережено, щоб не ламати посилання між квестами та вже записаний прогрес. Це не є гарантією сумісності будь-яких старих світів.

## Звіт про збій

Додай версію SOQM, ОС, версію Java, обсяг виділеної пам'яті, кроки відтворення, `logs/latest.log` і відповідний файл із `crash-reports/`, якщо він створений. Перед публікацією прибери особисті дані, адреси приватних серверів і токени. Не публікуй свої світи без перевірки їхнього вмісту.
