# Dimensional Dungeons у SOQM

## Що з'явилося

Dimensional Dungeons 210 додає повторювані експедиції через портал у власний
вимір `dimdungeons:dungeon_dimension`. Для доступу не потрібно генерувати нові
чанки Overworld: портал можна побудувати біля бази. Конструкцію порталу,
виготовлення й активацію ключів показують рідна книга Patchouli та JEI.

Це факультативна бойова гілка. Відвідування данжів не блокує технологічні
квести. SOQM 0.4.22 зберігає рідні Basic, Advanced і три початкові теми DD,
додає дві власні складні експедиції та окремий бойовий лут для данжів.
Рідний генератор DD складає нові експедиції з авторських кімнат SOQM;
адреси ключів, замки, ключники й повернення використовують механізми DD.

## Дві нові складні експедиції

| Експедиція | Розмір у конфігу генератора | Кімнати й тактика |
|---|---:|---|
| **Залізна цитадель / Iron Citadel**, тема 4 | 32 клітинки | Колони, укриття, барикади, перехресний вогонь і замкнені скарбниці |
| **Обсидіанова безодня / Obsidian Abyss**, тема 5 | 42 клітинки | Широкі переходи над ямами, драбини для повернення, магма в частині ям, слизькі підходи й флангові укриття |

Це цільовий розмір, який отримує рідний дизайнер DD, а не обіцянка точної
кількості кімнат у кожному випадковому плані. Кожна експедиція має по дев'ять
оригінальних шаблонів: **18 загалом**, із власними входами, перехрестями,
коридорами, поворотами та скарбницями. Шаблони мають розмір 16×13×16 блоків;
вони не копіюють кімнати інших модів.

Вхід безпечний. У звичайних кімнатах Цитаделі є 3–4 одноразово створені
вороги, у Безодні — 3; у кімнаті скарбниці — 4, включно з ключником.
Спавнерів і нескінченного відновлення хвиль немає. Посилені DivineRPG,
Twilight Forest і ванільні противники поєднуються з укриттями та небезпечною
геометрією. Для скарбниці потрібно здолати ключника й використати його ключ.

### Як відкрити

1. Пройдіть звичайну гілку DD до **Advanced** і оновіть портал двома
   Portal Crowns та придатними білими або фіолетовими настінними банерами.
2. У складній скрині **Advanced hard** є **25%** шансу на активований
   ключ **Залізної цитаделі**. Звичайні Basic, Advanced easy та crazy
   цей новий ключ не видають.
3. У замкненій скарбниці Цитаделі є **35%** шансу на активований ключ
   **Обсидіанової безодні** та окремий **25%** шанс на ключ нової Цитаделі.
4. У замкненій скарбниці Безодні є **25%** шансу на ключ нової Безодні.

Ці шанси застосовуються до відповідної скрині, а не до кожного вбитого
моба. Два кидки в Цитаделі незалежні: іноді можна отримати обидва ключі.
Нові ключі **вже активовані**: вставте їх в оновлений портал. Повторне
використання ключа веде за тією самою збереженою адресою; для свіжої
експедиції потрібен новий ключ. Випадкові порожні тематичні ключі DD
і звичайний дроп його мобів і далі відкривають тільки початкові теми 1–3.

У рідній книзі Dimensional Dungeons є розділ **«Експедиції SOQM»**
з українськими й англійськими поясненнями входу, небезпек і нагород.

## Квести: глава 23

У главі **«23 · Руїни, поселення та несподіванки»** є 12 необов'язкових
квестів із українськими й англійськими поясненнями. Гілка доступна після
початкового облаштування бази й не є передумовою технологічних квестів.

| Крок | Що перевіряє квест |
|---|---|
| Путівник | Саме книга Patchouli для Dimensional Dungeons |
| Портал | Один Portal Keyhole і два Gilded Portal Blocks в інвентарі |
| Перший ключ | Dungeon Key; активація перевіряється окремим кроком |
| Активація | Справжній ритуал активації базового ключа |
| Вхід | Перше відвідування виміру данжів |
| Повернення | Homeward Pearl |
| Власна активація | Знайдений Key Enscribing Station будь-якого з трьох ступенів зносу |
| Секрети | Знайдений Secret Bell |
| Просунутий ключ | Знайдений порожній Advanced Dungeon Key |
| Оновлення порталу | Дві Portal Crowns |
| Просунутий данж | Справжній перехід у просунутий данж |
| Колекція | Усі вісім рідних трофеїв, зібрані поступово |

Предметні задачі не забирають книгу, блоки, ключ чи перлину. Для інших етапів
використовуються досягнення самого DD: звичайний ключ не зараховує активацію,
а вхід у вимір не означає, що всі кімнати зачищені. Для колекції враховується
вся сукупність восьми критеріїв досягнення, а не один випадковий трофей.
Тематичні ключі пояснено в описах; окремої вигаданої перевірки «зачистити
тематичний данж» немає.

Портал потребує одного Keyhole, двох Gilded Portal Blocks і дев'яти придатних
Stone Bricks. Розташування показує багатоблокова схема в путівнику. Порожній
ключ активується на центральному отворі порожньої End Portal Frame або на
Key Enscribing Station; завершений портал у Край не потрібен. Активований
ключ відкриває свою адресу, тому повторне використання того самого ключа
веде в той самий данж. Для нового потрібен інший активований ключ.

Для просунутих данжів знайдіть Advanced Dungeon Key, активуйте його й
оновіть рамку двома Portal Crowns та білим або фіолетовим настінним банером
на кожній крайній колоні. Homeward Pearl повертає до **входу поточного данжу**;
додому веде портал. Зробіть для рецепта перлини запасний порожній ключ,
щоб не витратити єдиний ключ потрібної адреси.

Кожен квест має одну особисту прогресивну нагороду Expedition для кожного
учасника. Прев'ю доступне в книзі через Quest UI 0.4.8. Набір можливих призів
і виробничі обмеження залишаються чинними; гілка не видає безкоштовних ключів
або нових гарантованих Mayhem Cubes. Версія 0.4.22 уточнює опис просунутого
маршруту, зберігаючи всі ID, задачі, залежності, нагороди й особисту історію
отримань із 0.4.21. У повній книзі залишаються 1654 квести, 1940 задач
і 1655 зовнішніх слотів нагород.

## Які моби входять до наборів

| Джерело | Моби |
|---|---|
| DivineRPG, звичайний світ | Cave Crawler, Rotatick, Jungle Dramcryx, Desert Crawler, Enthralled Dramcryx, Glacon, Kobblin, Jungle Spider |
| Twilight Forest, ранні звичайні вороги | Kobold, Redcap, Skeleton Druid, Hedge Spider |
| Minecraft | Зомбі, скелети, vindicator, wither skeleton та тематичні звичайні вороги |

Базові набори поєднують crawler/rotatick/kobold із мобами дальнього бою.
Просунуті частіше використовують Enthralled Dramcryx і Jungle Spider.
Desert і Sewers отримали власні суміші. Nether Fortress зберігає рідні
набори з вогнестійкими ворогами, щоб лава не знищувала їх до зустрічі з гравцем.
Рідні спеціальні кімнатні виклики, зокрема mimic, також залишаються.

Це конкретні 8 типів DivineRPG і 4 типи Twilight Forest, а не всі моби цих
модів. Боси, торговці, домашні тварини, літальні/великі істоти, Arcana та
пізні виміри DivineRPG не включені. Їхні трофеї та матеріали не можна
отримати через ці нові набори, оминаючи відповідну прогресію.

## Підсилення Elite Mobs і Apotheosis

Окремий модуль SOQM додає кожному придатному звичайному ворожому мобу DD
одну справжню здібність Elite Mobs. Поза DD нові звичайні ворожі моби
DivineRPG мають шанс підсилення 12%, а боси DivineRPG — 85%. Це працює
і в Overworld, і в рідних вимірах DivineRPG. Боси зберігають свій тип,
місце появи, AI, фази бою та рідні нагороди; до нових наборів кімнат DD
їх не додано. Завантаження вже збереженої істоти не дає нового кидка.

Зустріч активується поблизу реального гравця, використовуючи його
поточний World Tier Apotheosis. Попередні tier-augment модифікатори
замінюються одним набором відповідного рівня, а інші модифікатори
істоти зберігаються. Налаштування визначає
`qm_dungeon_encounters-common.toml`:

| Зустріч | Множник HP | Множник шкоди |
|---|---:|---:|
| Звичайне підсилення | 1.5 | 1.15 |
| Advanced DD | 2.0 | 1.25 |
| Залізна цитадель | 2.5 | 1.35 |
| Обсидіанова безодня | 3.0 | 1.50 |
| Посилений бос DivineRPG | 1.25 | 1.10 |

Це іменовані додаткові множники SOQM, не кінцеві характеристики моба.
Дві нові експедиції використовують рівень здібності **Champion** у Elite
Mobs. Частка поточного HP зберігається, тому активація не повертає вже
пораненого ворога до повного здоров'я.

Пул здібностей: `brutal`, `infernal_touch`, `vampiric`, `withering`,
`shielded`, `reflective`, `regenerating`, `frostbound`, `abyssal`.
Їх виконують рідні обробники шкоди й tick-подій Elite Mobs. Істоти не
перетворюються на боса Lucifer: вони отримують окремі бойові здібності
моду зі збереженням UUID, AI, спорядження, ключів і рідного дропу.
Додаткове спорядження EliteLootTable не видається. Здібність, таймери й
одноразові ефекти зберігаються між перезапусками без повторного посилення.

Множники HP у власному конфігу Dimensional Dungeons дорівнюють 1.0, щоб
не множити базові характеристики двічі. Це не скасовує рідне правило DD:
вороги другого набору та keyholders отримують 1.5× HP, Strength II і
вогнестійкість. Точний результат залежить також від типу ворога та
налаштувань модуля зустрічей.

## Лут і ключі

Від 0.4.22 данжі мають власні профілі з бойовими нагородами:

| Скриня | Додаткова основна бойова нагорода |
|---|---|
| Basic easy, lucky | 35% шансу на спорядження **або** самоцвіт |
| Basic hard, Advanced easy | Одне спорядження **або** самоцвіт |
| Advanced hard, crazy | Одне спорядження **або** самоцвіт, із кращим набором запасів |
| Звичайна скриня Цитаделі | 45% шансу на спорядження **або** самоцвіт |
| Звичайна скриня Безодні | 60% шансу на спорядження **або** самоцвіт |
| Замкнена скарбниця Цитаделі | Одне спорядження **і** один самоцвіт |
| Замкнена скарбниця Безодні | Одне спорядження **і** один самоцвіт |
| Матеріальний kit | Попередній обмежений профіль Settlement |

Для змішаного призу співвідношення становить 45% спорядження / 55% самоцвітів.
Спорядження має справжні афікси Apotheosis; самоцвіти створює рідна функція
моду. **Рідкість і чистоту визначають World Tier та удача гравця, який
відкриває скриню**. Примусового Mythic або безкоштовного обходу рівня світу
немає. Базові скрині використовують залізні основи, складніші — діамантові;
також можливі лук, арбалет і щит. Додані предмети не беруться з необмеженого
пулу модового спорядження.

У запасах є їжа, стріли, золоті моркви/яблука, пляшечки досвіду, перлини,
справжні зілля лікування, регенерації, сили або вогнестійкості, залежно від
складності. **Gem Dust** призначений для покращення самоцвітів. Він також
може бути складником рецепта Sigil of Rebirth, але пил сам по собі не
замінює повного набору матеріалів для перековування.

Основні бойові призи мають пріоритет після захищених ключів і трофеїв,
тому звичайне скорочення запасів не видаляє гарантовану нагороду. Прибирається
й додатковий випадковий відсів цінних рідних предметів саме у DD. Водночас
кількість звичайних слотів, ресурсів, цінностей і фізична місткість скрині
залишаються обмеженими; точний обсяг пилу й запасів після відбору може
відрізнятися. Це не глобальне збільшення луту інших структур.

Рідні ключі, Homeward Pearl, Secret Bell, Key Enscriber, Portal Crown
та трофеї зберігаються. Вкладені таблиці книг і трофеїв не отримують
окремих додаткових кидків. Для нових кімнат таблиця призначається після
створення рідного замка, без завчасного заповнення: Lootr отримує контекст
кожного гравця при його першому відкритті.

Захищені предмети обробляються перед обмеженнями звичайного луту.
Складові ключа, включно з адресою данжу, його типом і темою, зберігаються;
ключі з різними адресами не об'єднуються. Рідний keyholder також залишає
свою іменовану палицю-ключ у нагрудному слоті, а виданий DD активований
ключ у другій руці не замінюється спорядженням Elite Mobs.

Дві рідні таблиці скориговано під дорогі рецепти майстерні SOQM.
`kit_redstone` дає невеликі партії redstone, кварцу, міді, заліза,
лазуриту й нитки замість готових поршнів, hopper і crafter.
`kit_pottery` дає глину, цеглу, горщики й sherds без готових печей.
Це не змінює таблиці скринь інших модів.

У v210 десять файлів кімнат містять п'ять старих посилань
`dimdungeons:chests/...`, хоча мод визначає таблиці як `dimdungeons:chest/...`.
SOQM додає для цих п'яти ідентифікаторів точні forwarding tables.
Це стосується `chestloot_2`, `chestloot_basic_easy`, `chestloot_basic_hard`,
`chestloot_advanced_hard`, `chestloot_lucky`. Власні кімнати й JAR моду
не перепаковуються для цієї поправки.

## Оновлення та перевірка

Конфіг ворогів застосовується до нових кімнат. Уже створені вороги та
відкриті скрині не перебудовуються. Для нових випробувань використовуйте
новий ключ/новий данж. Після оновлення сервер слід перезапустити.

DD 210 записує тему кімнати у збереження, але не відновлює її при читанні
готових кімнат і черги будівництва. Модуль SOQM відновлює цей запис лише
для відповідних авторських кімнат Цитаделі й Безодні. Завдяки цьому
незавершена експедиція після завантаження зберігає свої набори ворогів
і маршрути скринь; адреси ключів та інші поля збереження не переписуються.

Джерело наборів, скринь і винятків — `metadata/dimensional_dungeons.json`;
нагород — `metadata/dungeon_loot.json`; геометрії — `scripts/dungeon_rooms.py`.
Рідний загальний конфіг v210 має ім'я `config/dimdungeons-common-r210.toml`:
номер у назві є частиною зареєстрованого автором шляху.
Зміни генеруються командами:

```sh
python3 scripts/dimensional_dungeons.py
python3 scripts/dungeon_rooms.py
python3 scripts/exploration_loot.py
```

Перевірка відтворюваності й даних:

```sh
python3 scripts/dimensional_dungeons.py --check
python3 scripts/dungeon_rooms.py --check
python3 -m unittest discover -s tests -p 'test_dimensional_dungeons.py'
python3 -m unittest discover -s tests -p 'test_dungeon_loot.py'
```

За наявності зафіксованих JAR у `.cache/mods` тести додатково звіряють
їхні SHA-256, класи/ідентифікатори 12 модових ворогів, доступні рідні
loot tables, усі старі `LootTable`-посилання NBT-кімнат і захист рідних
ключів/трофеїв. Без завантажених залежностей ця частина позначається
як пропущена; перевірки згенерованого конфігу й балансних правил виконуються.

Тестовий `DungeonLootProbe` у нативному серверному harness викликає
фінальний mixin заповнення скрині для 12 початкових маршрутів, включно з kit.
Він використовує зареєстровані предмети DD і справжні компоненти ключів,
активованих API моду, перевіряючи їхню кількість і дані після відбору луту.
Окремий `DungeonRewardProbe` перевіряє всі 15 бойових таблиць, включно з
чотирма новими маршрутами, через справжні модифікатори луту й функції
Apotheosis для всіх п'яти World Tier та особисте заповнення Lootr.
Геометрію й маршрути порталів перевіряє
нативна фікстура експедицій. Фактичні результати й межі поточного
прогону наведені у [звіті перевірки](../reports/README.md).
Ці тестові моди не входять до інсталяційного ZIP.

NeoForge/FML 4.0.45 має штатну таблицю `VersionSupportMatrix`: для
Minecraft 1.21.1 вона підтримує fallback 1.21. Саме цей механізм обробляє
вказаний у metadata DD 210 діапазон Minecraft `[1.21,1.21.1)`.
SOQM використовує оригінальний файл моду й штатну сумісність лоадера.
