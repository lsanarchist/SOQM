# SOQM 0.4.9: виробничі гілки квестбука

**Дев’ять глав, 417 наявних квестів і 63 секції** тепер читаються як маршрути
виробництва: перший результат → робочий пристрій → подача й відведення →
автоматизація → розширення. Книга використовує ті самі задачі й нагороди;
змінюються їхній навчальний порядок, залежності, назви, пояснення та композиція.
Окремий квест RFTools Crafter Tier 1 підтримує ранній маршрут AE2, але глава
RFTools не входить до цих дев’яти карт.

Цей документ пояснює, як проходити нові гілки та як редагувати їхні джерела.
[Зміни версії й оновлення світу](CAMPAIGN_UPDATE.md) описують сумісність із
попередньою кампанією. [Головна карта](../assets/campaign-route.svg) зберігає
загальний маршрут через шість матеріальних рубежів.

## Як читати гілку

Секції всередині переглянутої глави йдуть згори вниз. Зв’язки означають
передумови, а назви секцій відповідають наступному практичному кроку.
Більша сітка, комірка або реактор не стають обов’язковою зупинкою лише через
свою ціну: додаткові варіанти відгалужуються від того пристрою чи матеріалу,
який вони розвивають. У відкритому квесті видно всі його передумови,
включно з потрібними вузлами інших глав.

Потримай предмети, потрібні для предметної задачі, в інвентарі **перед**
установленням або використанням у наступному рецепті. Більшість описаних
комплектів перевіряє саме наявність предметів. Опис також дає коротку
перевірку роботи, яку треба виконати у світі; вона не перетворює предметну
задачу на автоматичний лічильник виробництва.

## Ex Deorum → Ex Machinis: від ручного сита до ME

[Карта Ex Deorum — 28 квестів, 5 секцій](../assets/campaign-ex-deorum.svg) ·
[Карта Ex Machinis — 10 квестів, 3 секції](../assets/campaign-ex-machinis.svg)

### Спочатку отримай руду

Підготуй Oak Sieve і Stone Hammer. Молот перетворює Cobblestone на Gravel,
який стане першою сировиною сита. String Mesh виготовляється з дев’яти ниток.
Після встановлення сітки просій невелику партію гравію й перевір різні
результати. Уже ця сітка має рецепт залізних часток: базова ймовірність
однієї частки на звичайний блок гравію — **10%**. Це шанс рецепта, а не
гарантія результату за кожні десять блоків. Збери **чотири Iron Ore Chunk**,
склади їх у сітці 2×2 та отримай блок залізної руди для подальшої переробки.

Осмієві частки є окремою ранньою гілкою: у встановленому наборі модів для
String Mesh і Gravel також є їхній рецепт. Це додатковий результат,
який не змушує чекати залізної або діамантової сітки. Подрібнений глибинний
сланець має власні таблиці просіювання; вибирай сировину за потрібним
результатом у JEI.

### Автоматизуй перевірену операцію

| Крок | Що вже потрібно | Що зібрати й перевірити |
| --- | --- | --- |
| Перша руда | Oak Sieve, Stone Hammer, String Mesh | Cobblestone → Gravel → чотири залізні частки. Ключовий квест: `514011D7E21C7052` |
| Mechanical Sieve | Перша руда, Precision Mechanism і підготовлене живлення | Подай матеріал у вхід, установи придатну сітку, відведи результат із вихідних слотів. Квест: `5140118233B3CC83` |
| Mechanical Hammer | Освоєний ланцюг подрібнення, Dark Steel, точний механізм і живлення | Перевір Cobblestone → Gravel. У машині окремі слоти входу, необов’язкового інструмента та виходу |
| Flux Sieve / Flux Hammer | Відповідна Mechanical-машина та Expert-компоненти | Заверши попередній предметний квест перед витратою машини в рецепті. Під’єднай FE й окремий приймач |
| Подача гравію | Обидві Flux-машини та Item Buffer | Комплект задачі: Flux Hammer, Item Buffer і чотири Basic Logistical Transporter. Звір повний шлях до вихідної скрині. Квест: `514011F45FF8C855` |
| Більші партії | Налагоджена лінія, потім матеріали відповідного поліпшення | Gold → Diamond. Netherite є окремим пізнім розширенням |
| Результат у ME | Підготовлена лінія, Diamond Upgrade і перший справжній ME-крафт | Import Bus забирає дроп із **зовнішнього приймача**. Наявний фінальний комплект: Flux Sieve, Diamond Upgrade, Import Bus. Квест: `514011ADCD0AC819` |

Обидві Mechanical-машини вже використовують **FE**. У конфігурації збірки
Mechanical Hammer споживає **20 FE за робочий тик**, Mechanical Sieve —
**40 FE за робочий тик**. Окремого вигаданого ступеня з валами або ручним
приводом між ручним ситом і цими машинами немає. Рецепт Mechanical Sieve
не споживає сітку, а його робочий слот приймає придатну сітку для вибраного
матеріалу. Mechanical Hammer не вимагає Diamond Hammer: рецепт приймає
молот із відповідного тега, а внутрішній інструмент під час роботи є
необов’язковим.

Item Buffer має власний прямий рецепт, працює **без FE** й не потребує
Precision Mechanism. Він може штовхати матеріал до маршруту подачі.
Comparator Upgrade встановлюється саме у відповідний слот цього буфера;
Flux Compactor для нього не потрібний. Компонувальник часток у руду винесено
в окрему корисну гілку після першої лінії.

### Вибір сітки й збільшення партії — різні рішення

Flint Mesh та Iron Mesh мають прямі рецепти. Golden Mesh у збірці потребує
шасі, Diamond Mesh — точного механізму, але жодна з них не є обов’язковою
передумовою першого Mechanical Sieve. Netherite Mesh справді продовжує
Diamond Mesh через ковальський рецепт із незеритом і шаблоном.
Сітка визначає доступні таблиці дропу, поліпшення Flux — розмір і темп
партії. Перевіряй обидва параметри під потрібний матеріал.

| Поліпшення Flux | Модулів у слоті | Максимум предметів за цикл | Стандартний цикл | FE за оброблений предмет |
| --- | --- | --- | ---: | ---: |
| Gold | 1 / 2 / 3 | 2 / 4 / 8 | 160 тиків | 1280 |
| Diamond | 1 / 2 / 3 | 16 / 32 / 64 | 80 тиків | 2560 |
| Netherite | 1 | 64 | 20 тиків | 2560 |

Це максимуми стандартної конфігурації за достатнього живлення й подачі.
Три Diamond Upgrade у безперервному повному режимі дають середнє споживання
**2048 FE/t**, один Netherite — **8192 FE/t**. Підготуй генерацію, кабелі
та відведення до збільшення партії. Рецепт Diamond Upgrade споживає **три
золоті модулі** й Dimensional Matrix; Netherite Upgrade — **три діамантові**
та компоненти зоряного етапу. Задача на один попередній модуль не означає,
що цього одного вистачить для наступного рецепта.

Ці числа не описують Item Buffer: він не витрачає FE й уже намагається
передавати весь доступний вміст. Золотий модуль не скорочує його базовий
інтервал; діамантовий і незеритовий скорочують. Стиснені матеріали Ex Deorum
також мають окремі рецепти просіювання: пакування дев’яти блоків не слід
автоматично трактувати як дев’ять звичайних незалежних просіювань.

### Вихід сита та місце для результату

Flux Sieve штовхає результат у зовнішній інвентар, стандартно під собою.
Його внутрішній інвентар для труб є входом: **Import Bus на самому ситі
не витягує з нього предмети**. Постав шину на вихідну скриню або Item Buffer
і приєднай її до живленої ME-мережі з коміркою, вільним місцем та каналом.
**Простий імпорт працює до Diamond Upgrade**; фінальний наявний квест
перевіряє саме комплект масштабованої лінії.

У закріпленій версії Ex Machinis неприйнятий випадковий дроп може втрачатися,
коли приймач переповнений. Залишай запас порожніх слотів, перевіряй відведення
і завчасно вимикай сито редстоуном та зупиняй подачу. Сигнал заповнення буфера
сам по собі не гарантує місце для кожного нового типу предмета. Це пояснення
за результатом читання встановленого коду; оновлення книги не містить
бінарного виправлення або окремого доказу відсутності втрат.

Вода, компост, глина, порцелянова посудина та лава утворюють додаткову
утилітарну гілку. Наприклад, Dust і 1000 mB води в бочці дають глину;
глина з кістковим борошном — порцелянову суміш, а необпалений тигель
потрібно випалити. Уся ця гілка не стає умовою першої залізної частки.

**Джерело маршруту та механік:**
[`ex_deorum.json`](../metadata/quest_branches/ex_deorum.json), з точними
посиланнями на Expert-рецепти, конфігурацію та записи Ex Deorum 3.12 /
Ex Machinis 4.0.3. Залежності й координати слід дивитися в актуальному
згенерованому квестбуці; редакційний файл також містить упорядковані `routes`.

## AE2: від однієї комірки до великих мереж

[Карта Applied Energistics — 80 квестів, 12 секцій](../assets/campaign-ae2.svg)

### Мінімум, який уже працює

Перші секції готують кварц, Fluix, Inscriber, штампи й процесори. Calculation
Processor веде до Precision Mechanism; штампи та Inscriber пояснюються до
того, як книга просить готовий процесор. Після точного механізму основний
маршрут має такий вигляд:

| Етап | Послідовність | Що гравець перевіряє |
| --- | --- | --- |
| Одна комірка | Живлення й кабель → Terminal та 1k Item Storage Cell → ME Chest | Покласти предмети у мережеве сховище й забрати один назад. Квест ME Chest: `51301145AC657CE8` |
| Ручний ME-крафт | ME Chest → Crafting Terminal | Залишити один блок бруківки у сховищі та зробити дошки з колоди через сітку активного термінала. Квест: `513011AAD4652E6F` |
| Перший шаблон | Blank Pattern → Pattern Encoding Terminal → Crafting Pattern | Закодувати відомий рецепт верстака, наприклад дошки з колоди. Encoding Terminal потребує Engineering Processor |
| Виконавець | Crafting Pattern → Pattern Provider → Molecular Assembler | Шаблон лежить у Provider, Assembler стоїть поруч, є живлення й матеріали |
| Перше замовлення | Assembler та Crafting Unit → 1k Crafting Storage | Замовити малу партію дощок і побачити повернення результату. Квест CPU: `513011DEEBB429E9` |
| Зовнішня обробка | 1k CPU → Processing Pattern | Provider над піччю подає пісок, паливо підготовлено вручну, Import Bus знизу повертає скло. Квест: `513011F60668F4F2` |

**ME Chest з однією 1k-коміркою вистачає для цього початку.** ME Drive,
Gold Chest, Controller і Dimensional Matrix не є передумовами першого CPU.
ME Drive дає десять слотів для комірок як окреме розширення. Найменший CPU —
один блок 1k Crafting Storage; додаткові Unit або Co-Processor не є умовою
першого простого замовлення.

Рецепти збірки все ще поєднують моди. Molecular Assembler використовує
**RFTools Crafter Tier 1**, а Crafting Unit — **Ender IO Crafter**.
Книга підводить до цих вузлів до збирання відповідного блока. Один квест
RFTools отримав ранні передумови на точному етапі, оскільки його чинний
рецепт не споживає матриці; це зміна квестового маршруту.

### Термінал, автокрафт і обробка перевіряють різні речі

Квест першого Crafting Terminal зберігає **наявну перевірку справжнього
ручного крафту** в під’єднаній, живленій та активній ME-мережі. У момент
крафту мережеве сховище повинно містити хоча б один предмет. Звичайний
верстак, вимкнена мережа чи саме отримання термінала цю умову не замінюють.

Квест CPU зберігає предметну задачу. Його опис навчає запуску замовлення,
але готовність автоматичної системи гравець перевіряє за статусом CPU
і повернутим результатом. Processing Pattern також не налаштовує сторони,
живлення, паливо або реагенти зовнішньої машини самостійно.

У першій вправі з піччю важливо повернути заявлений у шаблоні продукт:
без скла в тій самій мережі CPU продовжить чекати. Import Bus забирає
результат у ME; Export Bus підтримує заданий запас; Pattern Provider видає
конкретні інгредієнти на замовлення; Storage Bus відкриває доступ до
зовнішнього інвентаря. Це різні ролі, які тепер пояснюються поруч із
першим застосуванням.

### Розширюй те, чого бракує

| Потреба | Окрема гілка | Важливе розрізнення |
| --- | --- | --- |
| Більше запасу | ME Drive, компоненти 4k → 16k → 64k → 256k, предметні й рідинні комірки | Більшу завершену комірку не потрібно виготовляти лише для переходу до іншого застосування компонента |
| Складніші замовлення | Пам’ять CPU від 1k до 256k, Co-Processor | Один CPU веде одне замовлення. Два незалежні одночасні замовлення потребують двох CPU; більша пам’ять має іншу роль |
| Більше пристроїв | Controller → Dense Smart Cable → P2P | У стандартному режимі звичайна гілка має 8 каналів, щільна — 32; перевіряти потрібно весь шлях до пристрою |
| Доступ без кабелю до гравця | Wireless Receiver → Access Point → Wireless Terminal → Wireless Crafting Terminal | Підготувати прив’язку термінала, живлення й покриття, потім перевірити доступ |

| Робота з об’ємом світу | Controller → Spatial IO → Spatial Explorer | Почати з перенесення одного дешевого блока; перевірити розміри, енергію та повернення |

ME P2P вивчається як налаштована пара на окремій живленій транспортній
мережі. Memory Card переносить налаштування входу на вихід; наявність
двох тунелів сама по собі не створює зв’язок. Більші CPU, бездротовий
доступ, Quantum і Spatial не стають обов’язковими передумовами першого
автоматичного виготовлення дощок.

наступна фабрика збільшує кількість одночасних операцій, не підміняючи
підготовку реагенту. Digital Miner не стає умовою Quantum Entangloporter,
а Entangloporter — умовою QIO Drive Array лише тому, що всі вони дорогі
вузли. Наявний фінальний ручний пункт рудної лінії залишається ручним
підтвердженням після власного пробного випуску.

Ядерна гілка ставить охолодження, зупинку й поводження з відходами до
першого контрольованого циклу. Вона зберігає наявні спеціальні задачі
поділу й синтезу та окреме ручне підтвердження охолодження. Зразок хімікату
у відрі не вважається доказом безперервного паливного потоку.

У Industrial Foregoing пластик можна отримати звичайною латексною лінією
або чинним альтернативним рецептом **1 HDPE Sheet → 3 Plastic**. Тому Dry
Rubber не є єдиною обов’язковою передумовою спільного квесту пластику.
Це маршрути виготовлення матеріалу: пластик і HDPE, як і раніше,
**не входять до нагород**. Для переробки руди показано повний порядок
Washing Factory → Fermentation Station → Fluid Sieving Machine, а для
вищих рамок — потрібні Pink Slime та Ether Gas.

У Mob Grinding Utils генетичний корм потребує **використаного зразка**,
а не порожнього Mob Swab. Для XP Solidifier потрібні наявні проміжні
вузли, а Entity Spawner споживає Solid XP Blocks. Підготовка цієї лінії
тепер передує поліпшенням площі спавнера. Типи предметних задач, допустимі
істоти та поведінка самих модів залишаються чинними.

**Джерело:** [`industry.json`](../metadata/quest_branches/industry.json)
містить тринадцять упорядкованих маршрутів і посилання на авторські рецепти,
нативні досягнення та посібники встановлених модів. Конкретний рецепт
кожного блока остаточно звіряй у JEI поточної збірки.

## Дев’ять карт і межі прев’ю

Карти Ex Deorum, Ex Machinis та AE2 наведено посиланнями на початку
відповідних розділів; решта шість — у таблиці вище. Разом це дев’ять
переглянутих глав. Окремий десятий SVG,
[головний маршрут](../assets/campaign-route.svg), дає загальний контекст кампанії.

Рендерер читає **фактичні згенеровані координати**, розміри, форми, кольори,
підписи та видимі залежності між показаними квестами. Стрілки не додаються
для декоративного відчуття прогресії. Нейтральні номерні позначки замінюють
предметні іконки; міжглавні передумови повністю перевіряються в книзі.
**Це прев’ю розташування, а не скриншоти Minecraft.** Вони не доводять
читабельність на певному масштабі клієнта, швидкість проходження або
правильність установленої виробничої лінії.

## Джерела та відтворення для редактора

Редаговані фрагменти лежать у
[`metadata/quest_branches/`](../metadata/quest_branches/).
[`campaign_branches.py`](../scripts/campaign_branches.py) перевіряє й
застосовує їх до наявних об’єктів кампанії.

| Поле джерела | Призначення |
| --- | --- |
| `chapters` / `summary` | Точне ім’я наявної глави та коротке пояснення обома мовами |
| `sections` / `slot` | Порядок секцій; кожен початковий слот використовується рівно раз, зберігаючи його ID зображень |
| `rows` | До п’яти позицій у рядку; `null` лишає проміжок. Кожен наявний квест розміщується рівно один раз |
| `quests` / `dependencies` | Повний бажаний список батьків за незмінними ID; граф перевіряється на цикли |
| `stage`, `optional` | Навчальний етап і роль гілки; обов’язкові рецептурні обмеження перевіряються окремо |
| `title`, `description` | Авторські українські та англійські назви й абзаци; ці описи мають пріоритет над старими уроками |
| `routes` | Упорядковані орієнтири маршруту. Кожний попередній вузол має бути предком наступного в реальному графі |
| `evidence` | Точний рецепт, конфігурація, ресурс або клас із закріпленого JAR і пояснення перевіреної механіки |

Фіксовані координати п’яти колонок — **−9.2, −4.6, 0, 4.6, 9.2**.
Порожні позиції дозволяють розвести основну лінію та варіанти. Секції
використовують усю ширину й розміщуються вниз за заданим порядком;
панелі та підписи зберігають старі ID.

Структура гілок застосовується після попередніх адресних виправлень,
але перед додаванням обов’язкових рецептурних рубежів та узгодженням етапів.
Тому редакційне перенесення вузла не відкриває рецепт раніше за матеріали.
Повні масиви задач і нагород звіряються з базою `abd73f1` через
[контракт збереження](../metadata/quest_branch_identity.json).

Після редагування джерел виконай у цьому порядку:

```sh
python3 scripts/campaign_refresh.py
python3 scripts/localize_english.py
python3 scripts/render_campaign.py
python3 scripts/soqm.py lock
./scripts/check
```

Окремий [нативний стенд](RUNTIME_VALIDATION.md) перевіряє потрібні сценарії
на справжньому серверному наборі. Для оновленого раннього ME-сценарію
використовується ME Chest з однією 1k-коміркою, без Drive і Controller.
Точні результати та хеші останнього виконання містить
[reports/README.md](../reports/README.md); сам цей опис не означає успішний
запуск. Графічний клієнт, малий survival-цикл кожної лінії та тривала
multiplayer-економіка потребують окремої ігрової перевірки.

## English

SOQM **0.4.9** turns **417 existing quests in nine chapters and 63 sections**
into production routes. Dependencies and teaching text explain a first usable
setup, its input and output, then expansions. All objectives and personal reward
objects remain unchanged. A separate RFTools Crafter Tier 1 quest supports the
early Molecular Assembler; RFTools is not a tenth flow chapter.

**Ex Deorum / Ex Machinis:** Stone Hammer and Oak Sieve → String Mesh → four
iron chunks → Mechanical Sieve → Flux Sieve → a fed Flux line → Gold and
Diamond batch upgrades → external-receiver ME import. Mechanical Hammer is
a parallel feed-preparation branch. Flint, iron, gold and diamond meshes are
choices with their actual recipes; Diamond Mesh is not required for the first
powered sieve. Netherite is a later expansion. Mechanical machines already use
FE, while Item Buffer uses none. Comparator Upgrade belongs to that buffer.

A Flux Sieve pushes drops into a separate chest or buffer. Its sided internal
handler does not allow extraction, so an Import Bus must target the receiver.
Importing also works before Diamond Upgrade; the existing final item task
assembles a scaled-line kit. The pinned sieve may lose rejected drops when its
receiver fills: leave spare slots and stop production early. This questbook
update does not patch that binary behavior.

**AE2:** quartz and processors → powered one-cell ME Chest → actual manual
Crafting Terminal craft → encoded Crafting Pattern → Provider → Assembler →
1k CPU → external Processing Pattern. The first setup needs no Drive, Gold
Chest, Controller or Dimensional Matrix. It retains the real RFTools Crafter T1
and Ender IO Crafter ingredients. Larger cells and CPUs, channels/P2P, wireless,
Quantum and Spatial become separate expansions. The terminal advancement
observes a real manual craft in a live network with nonempty storage; the CPU
item objective does not observe completion of an autonomous job. Test a small
request and confirm its output yourself.

The six other industry chapters are listed above, with their maps and scope.
The **nine chapter SVGs**, plus the separate Main Route SVG, use actual generated
coordinates and explicit visible local edges. Neutral numbered markers replace
Minecraft item icons. They are **layout previews, not in-game screenshots**.

Edit `metadata/quest_branches/*.json`: reuse every original section slot, place
every existing quest once in rows of up to five lanes, use `null` for gaps,
and supply exact dependencies plus both authored languages. Evidence records
point to the pinned recipes, resources or classes. Run refresh → English →
render → lock → check using the commands above. Consult
[current reports](../reports/README.md) for actual validation; fixture design
or compilation is not a passed native run. Upgrading from 0.4.8 preserves
personal claims and production discoveries; the older shared-to-personal
entitlement is historical. See [migration details](CAMPAIGN_UPDATE.md#english).
