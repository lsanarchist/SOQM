# Перевірка гри перед alpha

Це чекліст для реального графічного клієнта. Порожня позначка означає **не перевірено**. Статична перевірка файлів, історичний серверний звіт або успішна упаковка не закривають ці пункти.

Для кожного запуску запиши: версію SOQM і коміт, SHA-256 імпортованого ZIP, дату, ОС, відеокарту, Java, виділену пам'ять, кількість гравців і результат. Для збою додай кроки відтворення та журнал; для результату, який важко підтвердити журналом, — скриншот або короткий запис.

## Чисте встановлення та початок гри

- [ ] Готовий ZIP імпортується в новий профіль; усі залежності завантажуються без ручної заміни версій.
- [ ] Клієнт доходить до головного меню без помилок завантаження модів і ресурсів.
- [ ] Новий світ створюється; після виходу світ повторно відкривається.
- [ ] У вступній главі зрозуміло, з чого почати; текст, іконки та посилання відображаються.
- [ ] Книга квестів відкривається; доступна перша послідовність завдань, працюють залежності та отримання нагород.
- [ ] Отриманий прогрес, інвентар і нагороди зберігаються після повторного входу.
- [ ] Пошук предметів і рецептів працює; основні клавіші не мають конфліктів, що блокують гру.
- [ ] Власні текстури видно в інвентарі та світі; немає відсутніх текстур або помилок атласу.

## Ігрові системи

- [ ] Ранній маршрут проходиться в survival без команд і творчого інвентарю; витрачений час та місця зупинок записані.
- [ ] Для кожної великої гілки перевірено щонайменше один перехід до наступного етапу: предмет можна отримати, рецепт доступний, квест зараховується.
- [ ] Таблиці здобичі, персональні скрині та випадкові події перевірені в грі; нетипові нагороди перевірені також із заповненим інвентарем.
- [ ] Відвідувані виміри відкриваються; повернення й повторне завантаження світу працюють.
- [ ] Якщо реліз заявляє підтримку сервера: окремий сервер запускається, два клієнти підключаються, особистий/командний прогрес та нагороди працюють після перезапуску.

Ці проби не доводять повного проходження, балансу економіки або стабільності довгої сесії. Для таких тверджень потрібні окремі проходження й вимірювання. Час старту, споживання пам'яті та поведінку під навантаженням записуй разом із умовами; не перетворюй одну машину на універсальні системні вимоги.

## Верстак Modern Foundry

Помилку індексів у Modern Foundry 4.1.6 підтверджено за кодом; вона пояснює
розкладку піску після крафту пісковику. Модуль сумісності виправляє всі три
записи. Пункти нижче позначаються лише після перевірки у графічному клієнті;
перевірка файлів їх не закриває.

- [ ] Перевір Modern Foundry 4.1.6 та `qm-foundry-compat-0.4.15.jar` на клієнті
  й сервері. Використовуй окремий тестовий світ у survival.
- [ ] Поклади рівно 64 піски чотирма стеками по 16 у нижній правий квадрат
  2x2 верстака Modern Foundry. Забери один пісковик. Має залишитися
  **60 пісків і один пісковик**: по 15 у початкових слотах, решта п'яти порожня.
- [ ] Повтори в інших трьох кутах. Потім поклади по одному піску в кожен
  слот рецепта: один пісковик має витратити всі чотири піски, без нового результату.
- [ ] Повтори початкову дію масового крафту з Ctrl, записавши місце кліку;
  окремо перевір звичайне забирання й Shift+клік на результаті. Повний крафт
  64 пісків має дати **16 пісковиків**. Врахуй інвентар, сітку, курсор і предмети
  на землі, зокрема після закриття верстака та повторного входу.
- [ ] Повтори з майже заповненим інвентарем і сусіднім сховищем. Якщо результат
  переноситься лише частково, предмети не повинні губитися або додаватися.
- [ ] Перевір зсунутий рецепт 1x2, наприклад палиці, повний рецепт 3x3 та рецепт
  із поверненням відра чи іншої тари. Залишки мають потрапляти у фактичні слоти
  витрачених інгредієнтів або звичайним шляхом в інвентар чи на землю.
- [ ] Перевір перенесення рецепта JEI, сортування IPN та звичайний верстак
  зі збереженими налаштуваннями.

## Вибір рецептів майстерні

- [ ] У звичайному верстаку вручну виклади чотири залізні та три золоті
  шестерні за JEI. Перед забиранням перевір точний мод та ID результату.
  Повтори з горизонтально віддзеркаленою сіткою та після `/reload`.
- [ ] Зроби Stone-to-Iron із восьми блоків заліза навколо бруківки, а
  Copper-to-Iron — навколо мідного злитка. Перевір, що кожен комплект
  покращує відповідну встановлену піч.
- [ ] Повтори крафт шестерень і комплектів у верстаку Modern Foundry та
  через перенесення JEI. Заново запиши п'ять змінених шаблонів шестерень
  і Copper-to-Iron у наявних системах автокрафту AE2 чи інших модів.
- [ ] Перевір витрати: одна шестерня — чотири пластини й попередня шестерня;
  один комплект до залізної печі — вісім блоків заліза й центральний інгредієнт.

## Умови публічної alpha

Alpha можна випускати після чистого імпорту, успішного графічного запуску, перевіреного початкового survival-маршруту, збереження прогресу та відсутності відомих блокерів на перевіреному маршруті. Заявлені режими, зокрема сервер, повинні мати власний пройдений тест. Відомі проблеми й неперевірені гілки мають бути перелічені в релізі.

Для наступних статусів потрібні триваліші проходження всіх гілок, перевірка переходів між ними, повторне тестування нагород і рецептів, а також перевірка оновлення копії світу. Сам розмір книги квестів не є критерієм готовності.
